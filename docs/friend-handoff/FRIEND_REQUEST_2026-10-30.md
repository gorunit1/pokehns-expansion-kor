# 친구 요청 2026-10-30: 1.17.1 full-port 뒤 upstream 버그 수정 8건 선택 이식

사용자가 2026-10-30 전달한 원문이다(완료 단계 문자 보낸 뒤). 결과는 [`results/1.17.0-port/post-1.17.1-bugfixes.md`](results/1.17.0-port/post-1.17.1-bugfixes.md).

---

HnS 1.17.1 full-port 완료 후 upstream 버그 수정 선택적 이식 요청
1.17.1 full-port가 완료되면, 이후 pokeemerald-expansion에 병합된 버그 수정 중 아래 8건을 검토해 줘.

이번 작업의 목적은 1.17.2 개발 버전의 신규 기능을 가져오는 것이 아니라, 1.17.1 기반 HnS의 안정성을 높이는 것이야.

1. 우선 적용 요청 — 4건

다음 4건은 우선순위가 높은 버그 수정이므로, HnS의 현재 코드와 upstream PR의 변경 사항을 비교하고 문제가 남아 있으면 선택적으로 반영해 줘.
① #10953 — 날씨 중 반무적 기술 사용 시 assert 오류
https://github.com/rh-hideout/pokeemerald-expansion/pull/10953

* 비행, 구멍파기 등 반무적 상태가 발생하는 기술과 날씨 관련 assert 조건을 확인해 줘.
* 특히 `include/move.h`의 기존 assert 조건이 아직 남아 있는지 확인해 줘.
* HnS에도 해당 문제가 있다면 upstream 수정 내용을 반영해 줘.
* 기존 날씨 및 반무적 기술의 정상 처리에는 영향을 주지 않아야 해.

우선순위: 최상
② #10866 — 2대1 배틀 HP 박스 그래픽 손상
https://github.com/rh-hideout/pokeemerald-expansion/pull/10866

* 더블배틀 형식이지만 한쪽에 포켓몬이 1마리만 존재하는 상황에서 HP 박스가 손상되는 문제를 확인해 줘.
* HnS의 멀티배틀, 파트너 배틀 및 전용 HP 박스 코드를 고려해 줘.
* upstream의 좌표 및 그래픽 로딩 수정이 필요한지 확인하고, HnS 구조에 맞게 적용해 줘.
* 기존 메가진화 아이콘, 레벨 표시 및 HP 박스 관련 HnS 수정은 유지해 줘.

우선순위: 최상
③ #10974 — 맹독구슬·화염구슬 상태이상 방지 판정 오류
https://github.com/rh-hideout/pokeemerald-expansion/pull/10974

* 맹독구슬과 화염구슬이 발동할 때 상태이상 방지 조건을 잘못 판정하는 문제를 수정해 줘.
* 독·화상 면역, 특성, 타입 및 관련 상태이상 방지 조건을 확인해 줘.
* upstream에 추가된 자동 테스트도 HnS에서 활용할 수 있는지 확인해 줘.
* 기존 도구 발동 순서와 전투 규칙은 유지해 줘.

우선순위: 높음
④ #10972 — 난기류 비행타입 약점 판정 오류
https://github.com/rh-hideout/pokeemerald-expansion/pull/10972

* 난기류 상태에서 비행타입의 약점을 완화하는 판정이 비행타입과 관계없는 약점에도 적용되는 문제를 수정해 줘.
* 단일 타입 및 복합 타입 모두에서 정상적으로 처리되는지 확인해 줘.
* 기존 타입 상성, 특성, 테라스탈 및 날씨 처리와 충돌하지 않도록 해 줘.

우선순위: 높음

2. 추가 검토 — 4건

다음 4건은 곧바로 이식하지 말고, HnS에 같은 문제가 남아 있는지 먼저 확인해 줘.

| PR | 확인할 내용 |
|---|---|
| [#10933](https://github.com/rh-hideout/pokeemerald-expansion/pull/10933) | 포획한 포켓몬의 파티 편입 선택을 취소하면 진행 불능이 발생하는지 |
| [#10878](https://github.com/rh-hideout/pokeemerald-expansion/pull/10878) | 야생 포켓몬의 지닌 도구가 배틀 종료 후 정상적으로 복구되는지 |
| [#10910](https://github.com/rh-hideout/pokeemerald-expansion/pull/10910) | 배틀프런티어 트레이너가 의도하지 않은 다이맥스·테라스탈을 사용하는지 |
| [#10596](https://github.com/rh-hideout/pokeemerald-expansion/pull/10596) | 녹화 배틀 파티 저장 및 초기화 처리에 문제가 남아 있는지 |

특히 다음 사항을 지켜 줘.

* #10933: HnS의 자체 취소 처리와 비교하고, 이미 해결되어 있다면 수정하지 말아 줘.
* #10878: 여러 파일에 걸친 변경이므로 전체 코드를 무조건 가져오지 말고, 문제가 재현되는 경우에 필요한 수정만 가져와 줘.
* #10910: 배틀프런티어의 기믹 허용 규칙을 보존하고 의도하지 않은 발동만 수정해 줘.
* #10596: HnS에 이미 반영된 녹화 배틀 파티 관련 자체 수정은 보존하고, upstream의 남은 초기화 처리만 검토해 줘.

문제가 없거나 동일한 수정이 이미 반영된 항목은 중복 적용하지 않아도 돼.

3. 적용 원칙

1. 반드시 1.17.1 full-port 완료 이후의 HnS 코드를 기준으로 검토해 줘.
2. 각 PR의 실제 diff와 현재 HnS 구현을 비교해, 해당 문제가 존재하는지 먼저 확인해 줘.
3. 이미 해결된 부분은 수정하지 말고, 필요한 부분만 최소한으로 반영해 줘.
4. HnS 전용 시스템, 그래픽, 한국어 번역, 이벤트, 배틀프런티어 및 디버그 기능은 유지해 줘.
5. 기존 버그 수정과 무관한 리팩터링이나 신규 기능은 추가하지 말아 줘.
6. 사파리존 개편, 배틀시설 생성 리팩터, 전투 효과 시스템 전체 변경, 그래픽 압축 구조 변경 등 대규모 후속 변경은 이번 작업에서 제외해 줘.
7. `#10850`의 `OBJ_KIND_NORMAL` 초기화처럼 이미 HnS에서 해결된 항목은 다시 이식하지 말아 줘.

4. 검증 및 결과 보고

각 PR은 개별적으로 검토하고, 필요한 수정이 끝나면 기존 자동 테스트 및 관련 회귀 테스트를 실행해 줘.

실제 mGBA 조작과 화면·사운드 확인이 필요한 항목은 내가 별도로 검사할 테니, 재현 절차와 예상 결과를 함께 정리해 줘.

결과 보고에는 다음 내용을 포함해 줘.

* PR별 `APPLIED / ALREADY FIXED / NOT AFFECTED / DEFERRED` 결과
* HnS에서 문제가 발생하는 원인 및 해당 코드
* 수정한 파일과 적용한 변경 사항
* upstream 원본과 다르게 수정한 부분 및 그 이유
* 자동 테스트 결과
* 내가 mGBA에서 직접 확인해야 할 항목과 재현 방법
* 남아 있는 위험이나 미해결 문제

최종 목표는 1.17.1의 완성도를 유지하면서 확인된 버그만 안전하게 수정하는 것이야. 1.17.1 이후의 모든 upstream 커밋을 추가하는 작업으로 확대하지 말아 줘.
