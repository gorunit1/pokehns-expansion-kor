HnS 트레이너 그림 마무리 확인 및 실기 검사 계획
보고한 네 커밋과 코드·데이터 검증 결과 확인했어. 사용자 실기는 별도로 새 ROM에서 진행할게.

1. 웅 머그샷

`4b885582`에서 웅 그림일 때만 머그샷을 위로8px 옮기고, PNG·팔레트·일반 배틀 위치·다른 트레이너 머그샷·슬라이드 타이밍을 유지한 방향은 요청과 맞아.

일반 웅과 OBC 이후 웅의 Orange 머그샷을 각각 확인할게. 머리 잘림, 띠 아래 빈 줄, 슬라이드와 일반 배틀 발판 위치를 함께 보겠어. 그림 경계가 y10~74에서2~66으로 이동하는 점도 기록했어. 추가 수정은 실제 화면을 본 뒤 결정하자.

2. PARKER

`6d7ae678`의 수영팬티소년 클래스 복원과 Behavior Class 삭제 확인했어. 이름 지광·물속 OW·좌표(9,13)·파티를 유지하고, 배틀 앞모습은 새 수영팬티소년 그림을 사용하는 현재 방향으로 검사할게. 옛 앞모습으로 되돌리는 작업은 필요 없어.

상금·볼·BGM·AI가 기존과 같다는 코드 검증 보고는 보존하고, 나는 필드 배치·클래스·이름·새 앞모습을 실기로 확인할게.

3. 새 트레이너 그림 적용과 기존 그림 사용처

내가 보내준 그림 5종과 SoulGold 태권왕 그림을 게임에 넣었다는 보고 확인했어. 실제 모습은 새 ROM에서 내가 확인할게.

`biker_hns.png`는 배틀프런티어 시설에서 사용하는지 먼저 확인해 줘. 배틀프런티어에서 사용하지 않고, 다른 곳에서도 기존 폭주족 그림을 유지해야 할 이유가 없다면 새 폭주족 그림으로 그대로 덮어써도 괜찮아. 파일 이름을 따로 만들거나 새 그림 번호를 추가해야 한다고 요청한 것은 아니야.

반대로 배틀프런티어·배틀텐트·트레이너힐처럼 기존 그림을 보존하기로 한 곳에서 같은 파일을 사용한다면, 기존 파일은 유지하고 새 그림을 별도로 연결해 줘.

어느 방식이든 내가 보내준 그림의 픽셀과 색상은 그대로 유지하고, 배정 대상이 아닌 트레이너의 그림은 바뀌지 않도록 해 줘. 이미 적용한 내용을 다시 정리할 필요가 있는지는 사용처를 확인한 뒤 알려 줘.

4. 알로라 수영팬티소년과 미배치 인물 — 추천 선택안

배치된 `MELEMELE_SWIMMER_2` JIMMY와 `AKALA_SWIMMER_3` GEOFF 두 명도 새 수영팬티소년 앞모습으로 통일해 줘. 변경 범위는 두 엔트리의 그림 배정에 한정하고 클래스·파티·AI·상금·볼·BGM·OW는 그대로 유지해 줘.

이번에 배치되지 않은 KAZU와 수영팬티소년8명은 그대로 두자. 클래스 전체 일괄 변경이나 다른 지역/시설까지의 범위 확대는 하지 말아 줘. 두 명을 적용한 커밋과 보존 검증 결과를 알려주면 새 ROM에서 별도 확인할게.

5. 크레딧 및 다음 검증

태권왕의 SoulGold 출처와 원 축소자 미확인 표기를 유지해 줘. README에 나온 제작자 이름을 해당 그림의 직접 제작자로 단정하지 말고, 내가 제공한5종 이름 칸도 실제 제작자 정보가 확인될 때 채우자.

그리고 이미 soulgold에서 가져온 목호 및 심향 앞모습 스프라이트도 출처 명시가 지금 안되어있으면 출처 명시를 같이 하자.

빌드/정적 비교/자동 테스트와 사용자 mGBA 결과는 계속 구분하자. 실기에 사용할 ROM의 빌드 기준 커밋과 파일 해시도 함께 알려주면 기존 결과와 혼동하지 않고 검사할 수 있어.

나머지 full-sync는 기존 순서를 유지해 진행해 줘. Q1·Q2 승인 및 관련 검증·기존 한글 텍스트·메가 특성·세이브 보호 결정은 그대로 유지할게.
