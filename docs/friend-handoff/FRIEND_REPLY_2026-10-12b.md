HnS HGSS 트레이너 스프라이트 — 추가 결정 및 신규 에셋 전달
트레이너 복원 작업 결과 확인했어. 추가로 결정한 사항과 내가 새로 제작한 배틀 스프라이트 5종을 전달할게.

1. 웅(Brock) 머그샷 위치 보정

웅의 현재 머그샷과 목호·이향의 머그샷을 비교해 봤어.

웅은 다른 트레이너들보다 머리가 아래쪽에 위치해 있어서 머그샷에서만 Y 좌표를 8픽셀 위로 보정하고 싶어.

* 웅의 머그샷 Y 좌표: 현재보다 −8px
* 기존 `leader_brock_hns.png` 및 `.pal`: 변경하지 않음
* 일반 배틀 화면의 웅 스프라이트 위치: 변경하지 않음
* 다른 트레이너들의 머그샷 위치: 변경하지 않음


현재 `src/battle_transition.c`의 `Mugshots_CreateTrainerPics()`에서 웅의 Trainer Pic ID에만 세로 위치 보정을 적용하는 방식으로 처리해 줘.

현재 일반 배틀 화면에서는 웅이 발판에 자연스럽게 앉아 있으므로, PNG 내부 픽셀을 이동시키면 안 돼.

2. PARKER — 기존 HnS 설정으로 복원

PARKER는 원래 HnS에서 수영팬티소년이었고, 블루 체육관의 물속에 배치되어 있다는 사실을 확인했어.

따라서 PARKER는 HGSS의 선원 설정이 아니라 기존 HnS의 수영팬티소년 설정으로 되돌릴게.

* 이름: `지광` 유지
* 트레이너 클래스: `Swimmer M Hns` (수영팬티소년)로 복원
* 배틀 스프라이트: 기존 수영팬티소년으로 복원
* 오버월드: 현재 물속 수영 NPC 그림 유지
* 맵 위치: 기존 `(9,13)` 유지
* 소지 포켓몬·상금·BGM·AI 등 기존 전투 동작 유지


즉, 이번 HGSS 복원 작업에서 변경한 PARKER의 클래스와 배틀 그림만 기존 HnS 기준으로 되돌려 줘.

3. 신규 배틀 스프라이트 5종 전달

앞서 직접 제작하겠다고 했던 HGSS 트레이너 배틀 스프라이트 6종 중 5종을 완성했어.

PNG와 PAL을 모두 포함한 압축파일 `hns_trainer_sprites_16c.zip`을 이 메시지에 첨부할게.

압축파일 안에는 다음 파일들이 있어.

| 클래스 | PNG |
|---|---|
| 학원 끝난 아이 (School Kid) | `school_kid_hns.png` |
| 새 조련사 (Bird Keeper) | `bird_keeper_hns.png` |
| 포켓몬 매니아 (Poké Maniac) | `pokemaniac_hns.png` |
| 폭주족 (Biker) | `biker_hns.png` |
| 수영팬티소년 (Swimmer M) | `swimmer_m_hns.png` |

각 PNG에 대응하는 `.pal` 파일도 같이 포함되어 있어.

모두 다음 조건에 맞게 변환하고 검증한 최종본이야.

* 64×64 픽셀
* 인덱스 PNG, GBA 4비트 형식
* 투명색 포함 최대 16색
* 원본의 윤곽과 투명 영역 유지
* 원본의 색상을 최대한 보존하도록 최소한의 유사 색상만 통합

첨부한 PNG와 PAL을 최종본으로 사용해 줘.

기존 조사에서 HGSS 원작과 일치하는 배틀 그림을 확보하지 못했던 해당 5개 클래스에 적용해 줘.

필요하다면 신규 Trainer Pic ID를 추가해서 HGSS 스토리 트레이너에게만 배정하고, 기존 에메랄드 배틀프런티어·텐트·트레이너힐에서 사용하는 그림은 보존해 줘.

특히 PARKER의 수영팬티소년 복원과도 충돌하지 않도록 해 줘. PARKER를 포함해 실제 스토리에서 해당 클래스를 사용하는 트레이너는 이번에 전달한 새 그림을 사용하면 돼.

4. 태권왕(Black Belt) 스프라이트

마지막으로 남아 있던 태권왕 배틀 스프라이트는 직접 제작하지 않고 SoulGold의 것을 그대로 사용하기로 결정했어.

SoulGold 개발자에게 에셋 사용 허락을 받았으므로, SoulGold의 태권왕 배틀 스프라이트를 가져와서 HnS에 적용해 줘.

원본 그림을 우선 사용하되, GBA의 64×64·16색 규격에 맞지 않는 경우에는 원본 디자인과 색상을 최대한 유지하면서 필요한 형식 변환만 진행해 줘.

사용한 SoulGold 에셋과 확인 가능한 제작자 출처는 `CREDITS.md`에 기록해 줘.

태권왕 역시 기존 조사에서 확인된 HGSS 스토리 트레이너에게 적용하고, 배틀프런티어 등 다른 콘텐츠의 기존 그림은 유지해 줘.

이것으로 앞서 보류했던 HGSS 배틀 스프라이트 6종 모두 적용 방향을 확정한 거야.

5. 적용 후 검증

변경 사항을 반영한 뒤 다음을 확인해 줘.

* 웅 머그샷에서만 8픽셀 위로 보정되고 일반 배틀 위치는 그대로인지
* PARKER의 클래스와 배틀 그림이 수영팬티소년으로 복원되었는지
* 새 트레이너 스프라이트 5종의 PNG·PAL이 정상적으로 빌드되는지
* 태권왕 SoulGold 그림이 정상적으로 적용되는지
* 신규 그래픽 적용으로 기존 프런티어 트레이너나 다른 공용 스프라이트가 변경되지 않았는지
* 기존 상금·BGM·파티·AI·세이브 호환성이 유지되는지


실제 게임 화면에서의 그래픽 확인은 내가 mGBA로 진행할게.

첨부한 압축파일의 5종과 SoulGold 태권왕까지 반영하고, 웅 머그샷 및 PARKER 변경을 적용해 줘.
