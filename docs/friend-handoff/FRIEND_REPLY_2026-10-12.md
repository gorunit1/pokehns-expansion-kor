## 2. HnS 공식 한국어 번역 기준

우리 프로젝트의 공식 한국어 번역 우선순위는 다음과 같아.

**Champions > PLZA > SV > PLA > BDSP > SWSH > LGPE > USUM > SM > ORAS > XY > BW2 > BW > HGSS > Pt > DP > pokeemerald-kr**

이 우선순위는 동일한 기능이나 상황에 대응하는 공식 한국어 표현이 있을 때 적용하는 기준이야.

단, **NPC 대화와 포켓기어 텍스트에는 이 우선순위를 적용하지 않아.**

### 2-1. 전투·시스템 텍스트 번역 규칙

전투 메시지, 기술·특성·도구 설명, 메뉴, 시스템 메시지 등은 다음 규칙을 기준으로 해 줘.

1. **Poké Corpus의 공식 한국어 원문을 우선 확인해 줘.** 동일한 상황의 공식 문장이 여러 작품에 있다면 위 우선순위에 따라 가장 높은 작품의 문장을 사용해 줘.

2. **공식 원문의 표현, 조사, 어미, 띄어쓰기, 문장부호, 줄바꿈을 가능한 한 그대로 유지해 줘.** 단어가 같더라도 줄바꿈이 다르면 공식 원문과 완전히 일치한다고 판단하지 말아 줘.

3. **'HnS 관례'라는 이유로 공식 번역을 임의로 수정하지 말아 줘.** 특히 포켓몬 이름 다음에 줄바꿈하거나 주어와 서술어를 분리하는 등의 규칙을 임의로 만들지 말아 줘.

4. **HnS 화면 폭 때문에 공식 줄바꿈을 유지할 수 없다면 먼저 알려 줘.** 실제 렌더링 폭과 초과하는 부분을 확인하고 수정안을 제시해 줘.

5. **공식 게임에 대응하는 문장이 없는 HnS 고유 텍스트만 별도로 번역해 줘.** 이때도 최신 공식 게임의 용어와 문체를 기준으로 하되, 공식 번역과 자체 번역을 명확히 구분해 줘.

6. **포켓몬 이름·상대 구분·조사 등을 처리하는 기존 텍스트 변수는 유지해 줘.** 공식 문장을 옮길 때 HnS의 변수 치환 때문에 문법이나 의미가 달라지지 않는지 확인해 줘.

새로 번역할 때는 **공식 원문 확인 → 실제 상황 대조 → HnS 텍스트 변수 적용 → 출력 폭 검증** 순서로 진행해 줘.

### 2-2. NPC 대화·포켓기어 텍스트 예외 규칙

**NPC 대화와 포켓기어 텍스트에는 최신 작품별 번역 우선순위를 적용하지 말아 줘.**

HnS는 기본적으로 HGSS를 기반으로 하는 게임이므로, 스토리와 등장인물의 대사는 **HGSS 원작의 공식 한국어 텍스트를 최대한 보존**하고 싶어.

다음 기준을 적용해 줘.

1. HGSS에 동일한 NPC 대사나 포켓기어 문장이 있다면 **HGSS 공식 한국어 원문을 최우선으로 사용**해 줘.

2. 최신 작품에서 비슷한 표현을 사용하더라도 HGSS의 대사를 해당 표현으로 바꾸지 말아 줘.

3. 다만 **최신 포켓몬 게임의 문장부호 관례에 맞춰 문장 끝에 온점을 추가하는 정도의 최소한의 수정은 허용**할게. 모든 문장에 일괄적으로 온점을 추가하라는 뜻은 아니야.

4. HGSS 원문의 인물별 말투, 어휘, 문장 구성과 대사 흐름은 최대한 유지해 줘. 자연스럽게 만들겠다는 이유로 임의로 의역하거나 재작성하지 말아 줘.

5. HGSS에 없는 HnS 추가 NPC나 신규 이벤트 대사는 기존 HnS의 의도를 보존하면서 HGSS의 문체에 어울리게 번역하고 싶어.

6. 화면 폭이나 줄바꿈 문제가 있다면 실제 표시를 확인하고 필요한 최소한의 조정만 해 줘.

즉, **전투·시스템 텍스트는 최신 공식 번역을 기준으로 하고, NPC 대화·포켓기어 텍스트는 HGSS 원작 보존을 기준으로 한다**는 것이야.

### 2-3. 번역 작업 범위 — 기존 텍스트 임의 수정 금지

이 부분은 특히 중요하니 명확하게 전달할게.

**현재 HnS의 기존 텍스트는 내가 별도로 로컬에서 한글화 작업을 진행하고 있어.**

따라서 위의 번역 규칙은 앞으로 번역할 때 적용할 기준을 정한 것이지, 기존 HnS 텍스트를 전부 다시 번역하거나 정리해 달라는 요청이 아니야.

친구가 담당할 번역 작업 범위는 다음과 같이 정할게.

1. **pokeemerald-expansion 1.17.1까지 포팅하는 과정에서 새로 추가되는 배틀 메시지는 직접 공식 한국어로 번역해 줘.** 위의 최신 공식 번역 우선순위를 적용하면 돼.

2. **그 외 기존 HnS 텍스트는 내가 별도로 요청하지 않는 한 번역하거나 수정하지 말아 줘.** 영어로 남아 있더라도 임의로 한글화하지 않아도 돼.

3. **내가 명시적으로 요청한 번역 작업은 예외야.** 예를 들어 최근 요청한 트레이너 클래스명, 트레이너 이름 및 인물명 번역은 요청 범위에 해당하므로 진행해도 돼.

4. 기존 번역을 공식 한국어와 대조하면서 오류나 개선할 부분을 발견하더라도, 내가 요청하지 않았다면 직접 수정하지 말고 필요한 경우 알려 줘.

5. **NPC 대화와 포켓기어 텍스트도 내가 로컬에서 작업할 예정이므로 별도 요청 없이 번역하지 말아 줘.** 앞서 설명한 HGSS 원문 보존 규칙은 해당 번역을 진행할 때 적용할 기준이야.

6. 포트 과정에서 기존 텍스트 파일을 수정해야 한다면, **새 기능에 필요한 코드·텍스트만 최소 범위로 변경하고 기존 번역과 무관한 부분은 그대로 보존해 줘.**

7. 내가 로컬에서 진행하는 번역 작업과 충돌할 가능성이 있다면 먼저 알려 줘. 특히 기존 텍스트를 upstream의 영문 원문이나 다른 번역으로 덮어쓰지 않도록 주의해 줘.

정리하면 **친구는 1.17.1까지의 엔진 포팅과 신규 배틀 메시지 번역을 담당하고, 기존 HnS 텍스트의 한글화는 내가 로컬에서 담당**하는 방향이야.

내가 별도로 번역을 요청한 항목만 추가로 진행해 줘.

## 3. 메가진화 포켓몬 특성 정책 — 기존 HnS 설정 유지

**메가진화 포켓몬들의 특성은 내가 이미 현재 HnS에 직접 적용하고 각각 할당해 놓았어.**

여기에는 **pokeemerald-expansion 1.17.1에 추가될 `파동의방호`까지 포함**되어 있어.

관련 변경 사항과 특성 할당 내역도 모두 기존 인수인계 문서에 정리되어 있어.

따라서 남은 full-sync에서는 다음 원칙을 지켜 줘.

1. **기존 인수인계 문서의 메가진화 특성 적용·할당 내역을 먼저 확인해 줘.** 현재 HnS의 특성 할당은 내가 의도적으로 결정한 설정이야.

2. **upstream과 다르다는 이유만으로 HnS의 메가진화 특성을 변경하거나 되돌리지 말아 줘.** 충돌하는 경우 인수인계 문서에 기록된 HnS 설정을 우선 보존해 줘.

3. **1.17.1에 추가될 파동의방호도 이미 선반영하고 할당했으므로 보존해 줘.** 이후 해당 특성의 upstream 구현이 들어오면 기존 코드와 비교해서 중복 적용이나 설정 덮어쓰기를 방지해 줘.

4. 애니메이션이나 그래픽 수정 PR에 특성 변경이 함께 섞여 있다면, **그래픽 수정과 특성 데이터 변경을 분리해서 검토해 줘.**

5. 기존 특성 할당과 upstream 구현이 충돌하거나 인수인계 문서만으로 판단하기 어려운 경우에는 임의로 결정하지 말고 먼저 알려 줘.

이번 seq 283 #10270에서 대여르의 특성 변경을 제외한 것은 이러한 원칙에 부합해.

다만 묶음 15 요약에는 대여르 특성을 '불굴의마음×3'이라고 적었는데, 상세 결과 문서에는 `Defiant×3`이라고 기록되어 있어. `Defiant`는 '오기'이므로 서로 다른 특성이야.

**기존 인수인계 문서와 현재 코드에 기록된 실제 할당 값을 확인해서 어느 쪽이 맞는지 정리해 줘.** 확인 과정에서 기존 설정을 임의로 변경하지는 말아 줘.

앞으로 메가진화 관련 PR을 이식할 때도 이미 작업을 마친 특성들이 upstream 기본값으로 덮어써지지 않도록 주의해 줘.

## 4. full-sync 최종 목표를 1.17.1까지 확장

이전에 보내준 메시지에서 pokeemerald-expansion 1.17.1의 변경 사항에 관한 내용도 언급됐던 것으로 기억해.

**현재 진행 중인 full-sync의 최종 목표에 1.17.1까지 포함되어 있는지 확인하고 싶어.**

현재 작업 명칭과 포트 순서표는 `1.17.0 full-sync` 기준인데, 실제로는 1.17.1까지 반영할 계획인지 궁금해.

**만약 현재 목표가 1.17.0까지만이라면, 최종 포트 범위를 1.17.1까지 확장했으면 해.**

기본 방향은 다음과 같아.

1. **1.17.0 full-sync는 현재 계획대로 완료해 줘.** 지금까지 진행한 작업을 다시 시작하거나 기존 포트 순서를 불필요하게 변경할 필요는 없어.

2. **1.17.0 완료 이후 1.17.1까지의 추가 변경 사항도 반영하는 것을 최종 목표로 잡아 줘.** 필요한 후속 PR과 커밋을 조사하고 포트 계획을 확장해 줘.

3. 1.17.1이 아직 개발 중이거나 정식 버전이 확정되지 않은 상태라면 공개된 변경 사항과 예정된 변경 사항을 구분해 줘. 확인 가능한 변경은 사전 분석하고, 미완성 작업은 확정 이후 반영하도록 계획해 줘.

4. 이미 HnS에 선반영된 1.17.1 관련 기능은 무조건 다시 이식하지 말고 기존 구현과 upstream 변경 사항을 비교해 줘. 특히 파동의방호와 메가진화 특성 할당 내역은 반드시 보존해 줘.

5. **1.17.1 변경 사항도 기존 1.17.0 full-sync와 동일하게 HnS 고유 기능·스토리·그래픽·한국어 번역을 보존하면서 이식**해 줘.

6. 1.17.1 변경 사항 중 HnS의 기존 정책이나 게임 동작과 충돌하는 내용이 있다면 임의로 upstream을 우선하지 말고 별도로 질문해 줘.

7. **1.17.1까지 추가되는 신규 배틀 메시지는 공식 한국어로 번역하되, 그 외 기존 텍스트의 번역은 진행하지 않아도 돼.** 앞서 정한 번역 작업 범위를 그대로 유지해 줘.

가능하다면 현재 포트 계획을 검토해서 **1.17.0 완료 이후 1.17.1 반영까지 어떤 작업이 추가로 필요한지**도 정리해 줘.

이미 1.17.1까지 계획에 포함되어 있다면 기존 계획을 유지하면 되고, 아니라면 위 방향으로 확장해 줘.

최종적으로는 **HnS의 기존 고유 콘텐츠와 내가 작업한 한국어 번역·메가진화 특성 설정을 보존하면서 pokeemerald-expansion 1.17.1까지 동기화된 상태**를 목표로 하고 싶어.

## 5. 이번 묶음 15의 후속 처리

이번 묶음에서 요청하는 작업을 정리하면 다음과 같아.

- 진홍빛고동·하드론엔진 문장 4개를 SV·ZA 공식 원문의 줄바꿈과 일치하도록 수정
- 1.17.1까지 새로 추가되는 배틀 메시지에 최신 공식 한국어 번역 규칙 적용
- 기존 HnS 텍스트는 별도 요청이 없는 한 번역·수정하지 않고, 내 로컬 한글화 작업 보존
- 별도 요청한 트레이너 클래스명·트레이너 이름·인물명 등의 번역은 기존 결정대로 진행
- NPC 대화·포켓기어 텍스트는 HGSS 원작 보존 원칙을 적용하되, 내가 요청하기 전까지 번역 작업은 진행하지 않음
- 기존 인수인계 문서에 있는 메가진화 특성 할당 내역 재확인 및 보존
- 대여르 특성에 관한 요약·상세 문서 간 불일치 확인
- AI 교체 무한 루프 방지 가드 유지
- 현재 full-sync의 목표가 1.17.1까지인지 확인하고, 아니라면 1.17.1까지 포트 범위 확장

진홍빛고동·하드론엔진 문장 수정 뒤에는 빌드와 한글 회귀 검사를 진행해 줘.

그 외 seq 268~285의 이식 결과와 HnS 가드는 현재 보고한 방향대로 유지하면 돼.

**엔진 포팅은 친구가 계속 진행하고, 기존 텍스트 한글화는 내가 로컬에서 계속 진행할게.** 서로 작업이 충돌하지 않도록 이 원칙을 앞으로도 유지해 줬으면 해.

mGBA 실기 검사는 내가 새 테스트 ROM에서 직접 진행할게.
