### D. #9006 새 한글 문장 2개 — 확정

1. `gText_MoveRelearnerTeachMoveConfirmUseTm`: `{STR_VAR_2}{K_EULREUL} 배우게 하겠습니까?` / `{STR_VAR_3} 1개가 없어집니다`
   - `배우게 하겠습니까?`는 SV 공식 표현과 같다.
   - 소모형 기술머신 표현은 BDSP의 `한 번 사용하면 없어져 버린단다`, `없어지게 됩니다만 괜찮겠습니까?` 계열을 근거로 `1개가 없어집니다`를 유지한다.
2. `gText_MoveRelearnerStop`: `{STR_VAR_1}에게 새 기술을` / `배우게 하는 것을 그만두겠습니까?`
   - SV에 `[기술]을 배우는 것을 그만두겠습니까?`가 실제로 있어서 `그만두겠습니까?`를 그대로 쓴다.

참고(친구 확인): 둘 다 지금 HnS 일반 플레이에서는 나오지 않는다. 앞 문장은 `P_TM_MOVES_RELEARNER = FALSE`, 뒤 문장은 `P_SUMMARY_SCREEN_MOVE_RELEARNER`·`P_PARTY_MOVE_RELEARNER`가 FALSE라서다. 검은먹시티 NPC는 `RELEARN_MODE_SCRIPT`라 기존 `gText_MoveRelearnerGiveUp` 등을 쓴다. 결과 문서의 "한글 문구 미결" 표시는 확정으로 바꾼다.

### E. AI mGBA MCP 제안 — 시험 도입 찬성

- 처음부터 사람 실기 확인 전체를 대체하지 않고 **`AI 사전 확인` 용도**로 시작한다.
- **첫 시험: seq 107 #7305 나무열매 세이브 호환.** `results/1.17.0-port/berry-7305/`의 파일 기반 결과와, MCP로 실제 ROM을 띄워 메모리에서 읽은 결과가 정확히 일치하는지 먼저 대조한다.
- 첫 시험이 잘 맞으면 다음 범위까지 넓힌다.
  - 세이브 구조체, 플래그, 파티·박스, `berryTrees` 같은 메모리 값
  - Safari UI처럼 특정 장면의 정적 화면
  - 한글 글자 깨짐, 줄바꿈, 창 넘침, 픽셀 침범
  - 같은 `.sav`와 같은 입력을 쓴 이식 전후 화면 비교
- 계속 사람이 최종 확인하는 것: 애니메이션 자연스러움, 효과음과 타이밍, 체감 난이도, 긴 플레이 흐름, AI 행동이 실제 플레이에서 자연스러운지에 대한 최종 판단, 최종 PASS/FAIL 판정
- 운영 규칙은 PROPOSAL 5절 초안대로 한다.
  - MCP 설정은 저장소에 넣지 않고 사용자 범위로 설치
  - ROM·`.sav`·스테이트는 저장소 밖 별도 폴더 사용
  - 서로 다른 ROM 비교에는 세이브스테이트가 아니라 같은 게임 내 `.sav` 사용
  - AI 확인 결과는 `AI 실기 확인(mGBA MCP)`로 따로 표기하고 사람 실기 PASS와 섞지 않음
  - 스크린샷과 읽은 메모리 값은 근거로 남김
  - Lua는 메모리 쓰기나 세이브 조작처럼 꼭 필요할 때만 쓰고 매번 승인받음
- `mgba-live-mcp`를 쓴다면 PyPI 버전이 아니라 코드를 검토한 GitHub 커밋 `bacaf68`에 고정한다.
- 첫 시험이 기존 도구 결과와 맞지 않거나 세션 안정성이 떨어지면 확대를 멈추고 원인부터 확인한다.

### F. 사람 mGBA 직접 확인

- AI MCP와 별개로 사람 확인 목록은 지금 그대로 유지한다.
- 친구가 먼저 볼 항목
  1. 예측 AI 트레이너전(재대전 관장, FINLEY/MUALANI 더블, STEVEN 등): 멈춤, 이상한 기술 선택·교체, 턴 시작 지연

     - 기술 3개 이하 → 정상 습득 + 하트비늘 1개 감소

     - "배우게 하겠습니까?"에서 아니오 → 하트비늘 유지
     - 목록 취소·포기 → 하트비늘 유지

- AI MCP가 먼저 통과시킨 항목도 사람 확인 목록에서 지우지 않고 `AI 사전 확인 통과` 정도로 표시한다.

### G. 친구 로컬 작업 보존

- 친구 로컬은 지금 건드리지 않는다. local-only 커밋(`dac422efb3` 포함)은 full-sync가 끝날 때까지 그대로 보존한다.
- 친구는 지금 `git pull`·`push`·`rebase`·`reset`을 하지 않는다. full-sync가 끝난 뒤 완료 메시지와 최신 handback을 받고, 로컬 번역 커밋이 빠지거나 덮어써지지 않도록 통합 순서를 다시 잡는다.
- 같은 파일을 친구가 따로 고칠 일이 생기면 먼저 알린다.
