# 친구 요청 2026-10-22: 장소별 BGM을 HGSS 원작과 맞추기(관동 센터·체육관, 사파리존, 28번도로·은빛산, 방울탑 옥상·방울소리좁은길, 그 밖)

사용자가 2026-10-22에 전달한 원문이다. 이전 문자(묶음 24 알림, 10-21 반영)에 대한 답이 아니라 새 요청이다. 재확인 70·71·72와 실기 결과는 다루지 않는다. 첨부 파일은 없다.

---

HnS의 장소별 BGM을 HGSS 원작과 대조하면서 발견한 불일치들을 수정해 줘.

기본적으로 HGSS에 존재하는 장소는 원작의 BGM을 따르되, 아래에 명시한 HnS 전용 예외 사항은 유지하는 방향이야.

1. 관동지방 포켓몬센터 및 체육관

관동 포켓몬센터 11곳

현재 사용 중인 `MUS_RG_POKE_CENTER`를 모두 `MUS_HG_POKE_CENTER`로 변경해 줘.

* 상록시티, 회색시티, 블루시티, 갈색시티, 보라타운
* 무지개시티, 노랑시티, 연분홍시티, 홍련섬
* 4번도로, 9번도로 포켓몬센터

 관동 체육관 8곳

현재 사용 중인 `MUS_RG_GYM`을 모두 `MUS_HG_GYM`으로 변경해 줘.

* 상록시티, 회색시티, 블루시티, 갈색시티
* 무지개시티, 노랑시티, 연분홍시티
* 쌍둥이섬 강연 체육관


성도지방의 기존 포켓몬센터 및 체육관 음악은 변경하지 않아도 돼.

2. 연분홍시티 사파리존

현재 에메랄드의 `MUS_SAFARI_ZONE`을 사용하는 연분홍시티 사파리존 내부 4개 맵을 `MUS_HG_SAFARI_ZONE`으로 변경해 줘.

* `FuchsiaCity_SafariZoneBeach_hns`
* `FuchsiaCity_SafariZoneBrush_hns`
* `FuchsiaCity_SafariZoneMountain_hns`
* `FuchsiaCity_SafariZoneCave_hns`


사파리존 입구의 `MUS_HG_SAFARI_ZONE_GATE`는 그대로 유지해 줘.

서로 연결된 사파리존 내부 맵을 이동할 때 같은 음악이 끊기거나 처음부터 재생되지 않도록 해줘.

3. 28번도로 및 은빛산 외부

HGSS 원작에서는 28번도로, 28번도로의 집, 은빛산 외부가 모두 포켓몬리그 BGM을 사용해.

다음 3개 맵을 `MUS_HG_POKEMON_LEAGUE`로 통일해 줘.

| 맵 | 현재 설정 |
|---|---|
| `Route28_hns` | `MUS_HG_ROUTE26` |
| `Route28_House_hns` | `MUS_HG_ROUTE26` |
| `MtSilver_Outside_hns` | `MUS_HG_VICTORY_ROAD` |

중요한 것은 세 장소 사이의 음악 연속성이야.

* 28번도로 ↔ 은빛산 외부
* 28번도로 ↔ 28번도로의 집


서로 같은 BGM을 사용하는 장소를 이동할 때 음악이 멈추거나 페이드아웃되지 않고, 처음부터 다시 재생되지도 않도록 확인하고 필요한 부분을 수정해 줘.

단순히 `map.json`의 음악 ID만 바꾸는 것으로 충분한지, 맵 연결 및 워프 과정의 음악 처리도 함께 확인해 줘.

26번도로와 28번도로처럼 서로 다른 BGM을 사용하는 경계에서는 정상적인 음악 전환이 이루어져야 해.

4. 방울탑 옥상과 방울소리좁은길

방울탑 옥상

* `TinTower_RoofDay_hns`
* `TinTower_RoofNight_hns`


현재의 `MUS_HG_BELL_TOWER`를 제거하고, 레드가 있는 은빛산 정상의 HnS 바람소리를 사용하도록 수정해 줘.

현재 은빛산 정상은 `MUS_NONE`과 `SE_M_BLIZZARD`를 사용하는 구조로 확인했어.

`MtSilver_SummitDay_hns`의 기존 처리를 참고해서 방울탑 옥상에서도 동일한 환경음이 들리게 해줘.

다만 은빛산 정상의 다른 스크립트나 레드 이벤트까지 복사하지 말고, 환경음에 필요한 부분만 적용해 줘.

* 옥상 진입 시 바람소리가 정상적으로 시작될 것
* 옥상을 떠날 때 환경음이 정상적으로 정리될 것
* 낮과 밤 모두 동일하게 적용될 것
* 재진입이나 이벤트 종료 후 소리가 중복 재생되지 않을 것
* 기존 호오 이벤트와 기모노 소녀의 춤 음악, 전투 음악은 유지할 것

 방울소리좁은길

`BellchimeTrail_hns`는 HGSS 원작처럼 별도의 BGM이 없는 장소로 변경해 줘.

일반 음악은 재생하지 않되 발소리 등 기존 효과음은 정상적으로 들려야 해.

5. 나머지 HGSS BGM 불일치 수정

다음 장소들도 HGSS 원작 설정에 맞춰 변경해 줘.

| 장소 / 대상 맵 | 변경할 BGM |
|---|---|
| `CliffEdgeGate_hns` (벼랑끝 게이트) | `MUS_HG_ROUTE34` |
| `EmbeddedTower_hns` (매몰탑 내부) | `MUS_HG_UNION_CAVE` |
| `RuinsOfAlph_PuzzleAndRewardChambers_hns` | `MUS_HG_UNION_CAVE` |
| `RuinsOfAlph_WordsRoom1_hns` ~ `WordsRoom4_hns` | `MUS_HG_UNION_CAVE` |
| `GoldenrodCity_UndergroundSwitches_hns` | `MUS_HG_UNION_CAVE` |
| `GoldenrodCity_UndergroundStorage_hns` | `MUS_HG_UNION_CAVE` |

알프의 유적은 모든 구역을 연결동굴 BGM으로 바꾸라는 의미가 아니야. HGSS 원작에서도 지하 홀 등은 알프의 유적 고유 BGM을 사용하므로, 기존에 원작과 일치하는 구역은 그대로 유지해 줘.

금빛시티 지하통로와 지하창고도 원작의 기본 BGM을 적용하되, 로켓단 관련 이벤트에서 별도 음악이 필요한 경우에는 이벤트 음악이 정상적으로 우선하도록 해줘.

6. 변경하지 않을 장소

다음은 원작과 BGM이 다르더라도 HnS의 현재 설정을 유지하기로 결정했어.

* `MtMoon_Outside_hns` — `MUS_HG_MT_MOON_SQUARE` 유지
* `MtMoon_Shop_hns` — `MUS_HG_MT_MOON_SQUARE` 유지


달맞이산 광장과 상점은 HGSS 원작의 평상시 BGM으로 변경하지 않을 거야.

또한 HnS 고유 콘텐츠처럼 HGSS에 직접 대응하는 장소가 없는 곳은 이번 수정 대상에 임의로 포함하지 말아 줘.

7. BGM 연속성 및 이벤트 처리

이번 변경은 단순히 맵의 음악 ID를 교체하는 것에서 끝나지 않았으면 해.

같은 BGM을 사용하는 인접 맵 사이에서는 이동할 때 음악이 자연스럽게 이어지도록 확인해 줘.

특히 다음 사항을 확인해 줘.

1. 같은 음악을 사용하는 맵 사이에서 불필요한 페이드아웃이나 재시작이 발생하지 않을 것.
2. 맵 연결 이동과 출입구 워프 양쪽에서 정상적으로 작동할 것.
3. 다른 BGM을 사용하는 장소로 이동할 때는 정상적으로 전환될 것.
4. 환경음만 사용하는 방울탑 옥상과 방울소리좁은길에서는 이전 맵의 음악이 남지 않을 것.
5. 이벤트 전용 BGM, 전설의 포켓몬 등장 연출, 전투 음악 및 이벤트 종료 후의 음악 복원이 깨지지 않을 것.


공통 음악 재생 함수를 불필요하게 변경하지 말고, 기존 엔진에서 같은 BGM을 이어 재생하는 처리가 있다면 최대한 활용해 줘.

8. 작업 범위 및 보고

이번에 나열한 장소 외에도 작업 중 HGSS 원작과 다른 BGM 설정을 발견하면 함께 확인해 줘. 다만 HnS가 의도적으로 사용하는 전용 음악이나 추가 콘텐츠의 음악은 임의로 교체하지 말아 줘.

변경을 완료하면 다음을 정리해서 알려줘.

* 수정한 파일 및 장소 목록
* 변경 전후 음악 ID
* 인접 맵 사이의 음악 연속성을 위해 수정한 부분
* 기존 이벤트 음악에 영향을 줄 가능성이 있는 부분
* 추가로 발견한 불일치 및 판단이 필요한 항목

 빌드와 mGBA 실기 검사는 내가 직접 진행할 테니, 이번에는 코드 수정과 정적 확인까지만 진행해 줘. 기존 게임 로직과 이벤트 진행은 음악 변경에 필요한 범위 외에는 건드리지 말아 줘.
