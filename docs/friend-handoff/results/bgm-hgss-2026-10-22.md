## 2. 음악 연속성 — `map.json`만으로 되는가

**된다.** 엔진이 이미 "같은 곡이면 그대로"를 처리하고, 이번에 바꾼 맵의 스크립트에는 음악을 건드리는 줄이 없다(28번도로·은빛산 외부 `ON_TRANSITION`은 출현 시간대 설정뿐, 사파리 4맵·유적 방·매몰탑·게이트도 없음).

- **워프(출입구·계단):** `TryFadeOutOldMapMusic`이 목적지 곡(`GetWarpDestinationMusic`)이 지금 곡과 같으면 페이드하지 않는다. 도착 뒤 `Overworld_PlaySpecialMapMusic`도 같으면 다시 틀지 않는다(`if (music != GetCurrentMapMusic())`).
- **맵 연결(걸어서 넘어감):** `LoadMapFromCameraTransition` → `TransitionMapMusic`이 곡이 다를 때만 페이드 전환한다.
- **확인한 경계:**

  | 경계 | 방식 | 결과 |
  |---|---|---|
  | 28번도로 ↔ 은빛산 외부 | 연결 | 같은 곡 → 이어짐 |
  | 28번도로 ↔ 28번도로의 집 | 워프 | 같은 곡 → 이어짐 |
  | 28번도로 ↔ 26번도로(북) | 연결 | `MUS_HG_ROUTE26`으로 페이드 전환 |
  | 28번도로 ↔ 리셉션 게이트 | 워프 | `MUS_HG_ROUTE26`으로 전환 |
  | 은빛산 외부 ↔ 은빛산 센터 / 동굴 | 워프 | `MUS_HG_POKE_CENTER` / `MUS_HG_LIGHTHOUSE`(원작 동굴 `SEQ_GS_TO_TOUDAI`와 같음)로 전환 |
  | 사파리 해변 ↔ 덤불 ↔ 산 | 연결 | 같은 곡 → 이어짐 |
  | 사파리 산 ↔ 동굴 | 워프 | 같은 곡 → 이어짐 |
  | 사파리 해변 ↔ 입구 | 워프 | `MUS_HG_SAFARI_ZONE_GATE`로 전환 |
  | 유적 퍼즐방 ↔ 문자방 ↔ 바깥 | 워프 | 같은 곡 → 이어짐. 지하 홀(`B1F`)로는 유적 곡으로 전환 |
  | 방울소리좁은길 ↔ 인주시티 | 연결 | `MUS_NONE`으로 페이드(앞 곡이 남지 않음) |
  | 방울소리좁은길 ↔ 방울탑 1층 | 워프 | 무음 ↔ 방울탑 곡 |
  | 방울탑 8층 ↔ 옥상 | 워프 | 방울탑 곡 ↔ 무음 |

- `MUS_NONE`(0xFFFF)은 `PlayBGM`에서 0번(무음) 곡으로 바뀌므로 이전 맵 음악이 남지 않는다. `TransitionMapMusic`은 `MUS_NONE`일 때 파도타기 곡 덮어쓰기도 하지 않는다(기존 은빛산 정상과 같음).
- 공통 음악 함수(`TransitionMapMusic`, `TryFadeOutOldMapMusic`, `Overworld_PlaySpecialMapMusic`, `sound.c`)는 바꾸지 않았다.

## 3. 금빛 지하 스위치방·창고와 로켓단 점거 (`fc5ff3fc`)

- HnS는 `IsRocketTakeover`(`src/overworld.c`)에서 `VAR_MAHOGANY_TOWN_STATE == 16`(점거 중)이면 금빛시티·라디오타워·지하 입구·지하 통로를 `MUS_HG_ROCKET_TAKEOVER`로 바꾼다. 스위치방·창고는 맵 음악 자체가 점거 곡이었다.
- 맵 음악을 연결동굴 곡으로 바꾸면서 두 맵을 이 목록에 넣었다. **점거 중에는 지금처럼 점거 곡, 그 밖에는 연결동굴 곡**이다. 스위치방 실버 이벤트의 `fadedefaultbgm`도 점거 중이면 점거 곡으로 돌아간다(이전과 같음).
- 참고: 원작 HGSS의 점거 덮어쓰기는 라디오타워 7맵뿐이다(`sys_flags.c` `sMusicOverrideMap`). 금빛시티·지하까지 점거 곡인 것은 HnS 선택이라 유지했다.
- **같이 고친 버그:**
  - `IsRocketTakeover`의 `IS_MAP`이 인자 `warp`가 아니라 **현재 위치**를 봤다. `TryFadeOutOldMapMusic`·`TransitionMapMusic`은 위치가 바뀌기 전에 목적지 곡을 묻는다. 그래서 점거 중에 점거 맵을 떠나면 모든 목적지가 점거 곡으로 계산됐다.
  - 결과(코드 해석): 금빛시티에서 34·35번도로로 걸어 나가면 도로에서도 점거 곡이 계속 났다. 점거 맵에서 건물로 워프하면 페이드 없이 곡이 끊겼다.
  - 이번 변경 뒤에는 창고 → 백화점 지하, 스위치방 → 창고에서도 같은 일이 생기므로 `IS_MAP`이 `warp`를 보게 고쳤다. 현재 위치를 물을 때(`GetCurrLocationDefaultMusic`)는 결과가 같다.

## 4. 방울탑 옥상 바람 (`c5415296`)

은빛산 정상(`MtSilver_SummitDay_hns`)에서 환경음 부분만 옮겼다. 레드 이벤트·다른 스크립트는 복사하지 않았다.

- 은빛산 정상 구조: 맵 음악 `MUS_NONE`, `ON_FRAME`에서 `VAR_TEMP_MTSILVER_RESUME_BLIZZARD_SE == 0`이면 `playse SE_M_BLIZZARD` + 변수 1. `SE_M_BLIZZARD`는 끝에 `GOTO`가 있는 **반복 효과음**(SE1 플레이어)이다. 시작 메뉴를 닫을 때 `HideStartMenu`가 변수를 0으로 돌려 다시 튼다.
- 옥상 적용:
  - 두 맵 `MUS_NONE`.
  - `TinTower_Roof_OnFrame`/`TinTower_Roof_Wind`(낮 맵 스크립트에 두고 밤 맵도 같은 표를 씀). 변수는 `VAR_TEMP_TINTOWER_RESUME_WIND_SE`(= `VAR_TEMP_B`, 방울탑 스크립트에서 안 씀)이다.
  - `HideStartMenu`에 `MAPSEC_TIN_TOWER` + 옥상 레이아웃 조건을 추가했다.
- **시작:** 진입하면 임시 변수가 0이라 한 번 튼다. 같은 SE1 플레이어 하나라 겹쳐 나지 않는다(다시 틀면 처음부터).
- **정리:** 옥상 출구(8층으로 가는 계단 워프)는 `DoWarp`/`Task_StairWarp`가 `SE_EXIT`(SE1)를 틀어 바람을 덮는다. 옥상은 `allow_escaping false`.
- **이벤트 뒤:**
  - 호오 배틀 두 곳(이야기·전당 뒤) 모두 `waitstate` 직후 변수를 0으로 돌린다. 그래서 스크립트가 끝나면 바람이 한 번 다시 난다. 배틀에서 돌아오면 맵 음악은 `MUS_NONE`(무음)이다.
  - 기모노 춤은 그대로다(`playbgm MUS_HG_KIMONO_GIRL_DANCE`, 꽃잎춤 SE가 바람을 덮음). 춤 뒤에는 이전과 같이 춤 음악이 이어진다.
- **이벤트 스크립트 수정 1줄:** `TinTower_RoofDay_EventScript_HoOh` 첫머리의 `waitse`를 지웠다.
  - 바람은 끝나지 않는 루프라, 바람이 나는 중에 호오에게 말을 걸면 `waitse`(`IsSEPlaying()`)가 끝나지 않아 **소프트락**이 난다. 옥상에 다시 들어왔을 때 호오가 있거나, 춤 뒤 메뉴를 열었다 닫은 경우다.
  - 정상 흐름에서 이 `waitse`가 기다릴 소리는 없다. 앞의 춤 스크립트가 꽃잎·날갯짓 소리를 이미 `waitse`로 기다린다.
  - 배틀 쪽은 시작 때 SE가 30프레임 넘게 남으면 SE1·SE2를 멈추므로(`battle_gfx_sfx_util.c`) 막히지 않는다(은빛산 레드전과 같음).
- 밤 옥상 맵은 8층의 `TinTower_8F_EventScript_SetWarp`(어디서도 안 불림)로만 가므로 일반 진행에선 못 간다. 요청대로 같은 바람을 넣었다.

## 5. 기존 이벤트 음악에 영향이 있을 수 있는 곳

1. 금빛 지하 점거: 점거 중 스위치방·창고 곡은 이전과 같다. `IS_MAP` 수정으로 **점거 중 금빛시티 → 34·35번도로**는 이제 도로 곡으로 바뀐다(이전엔 점거 곡이 이어짐). 점거 맵 → 건물 워프는 페이드한다.
2. 방울탑 옥상: 호오 배틀 뒤 무음 + 바람(이전엔 방울탑 곡). 호오 이벤트 `waitse` 삭제.
3. 춤 도중 시작 메뉴를 열었다 닫으면 춤 음악 위에 바람이 함께 난다(은빛산과 같은 재개 방식).
4. 방울소리좁은길: 무음. 이 맵 스크립트에는 음악 명령이 없다.
5. 28번도로·은빛산 외부·사파리·센터·체육관·게이트·유적·매몰탑: 음악 명령 없음, 맵 곡만 바뀜. 체육관 판정(`event_object_movement.c`)은 `MUS_HG_GYM`도 포함한다.

## 8. 실기(mGBA) 후보 — 친구

1. 28번도로 ↔ 은빛산 외부(걸어서), 28번도로 ↔ 집(출입): 리그 곡이 끊기지 않음. 28번도로 ↔ 26번도로: 곡 전환.

6. 금빛 지하 점거 중: 통로 ↔ 스위치방 ↔ 창고에서 점거 곡 이어짐, 실버 이벤트 뒤 점거 곡. 점거 중 금빛시티 → 34·35번도로로 걸어 나가면 도로 곡. 점거 뒤: 스위치방·창고 연결동굴 곡.
