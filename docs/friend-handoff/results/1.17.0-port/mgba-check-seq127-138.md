## 3. 지닌 도구 발동 팝업 전수 대조 (요청)

- 멘탈허브는 기능·문장은 정상이지만 HnS에서 도구 팝업이 뜨지 않는다(`BattleScript_MentalHerbCureRet`가 `B_ANIM_HELD_ITEM_EFFECT`만 재생하고 `BattleScript_ItemPopUp`을 부르지 않음, upstream 1.17.0도 같음). Champions에서는 멘탈허브 발동 시 팝업이 뜬다 → **수정 대상**.
- 요청 사항

  2. Champions에서 같은 도구 발동 시 팝업 O/X 조사
  3. Champions와 다른 HnS 경로 목록
  4. 기능적으로 대응하면 Champions 표시 방식에 맞게 코드 수정
