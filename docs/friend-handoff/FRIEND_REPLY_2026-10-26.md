## 1. 재확인 99 — Champions 배틀 메커니즘

**seq 475.5의 #10151과 seq 475.8의 #10282를 HnS에 맞게 반영해 줘. 신규 설정 14개는 `GEN_LATEST`를 유지하고, 일괄적으로 `GEN_9`에 고정하지 말아 줘.**

현재 HnS의 `include/config/general.h`는 `GEN_LATEST = GEN_CHAMPIONS`이므로, 새 설정도 이 값을 따르게 해서 구현된 Champions 분기가 적용되도록 해 줘.

확인한 [HnS 설정](https://github.com/gorunit1/pokehns-expansion-kor/blob/12dbb610/include/config/general.h)과 달리, [upstream `expansion/1.17.0` 원본](https://github.com/rh-hideout/pokeemerald-expansion/blob/expansion/1.17.0/include/config/general.h)은 `GEN_LATEST = GEN_9`야. 같은 이름이어도 HnS와 적용 세대가 다르므로, **“HnS의 기존 Champions 설정에 맞춰 신규 메커니즘을 반영”**이라고 기록해 줘. “upstream 기본값 자체가 Champions”라고 적지는 말아 줘.

### 1-1. 적용할 설정

다음 14개 설정은 `GEN_LATEST`로 유지해 줘.

| 설정 | Champions 분기의 적용 내용 |
|---|---|
| `B_PARALYSIS_CHANCE` | 마비로 행동하지 못할 확률 12.5% |
| `B_MEGA_EVO_SPEED_SWAP` | 메가진화 시 스피드스왑으로 교환한 스피드 보존 |
| `B_FREEZE_TURNS` | 해동 확률 25%, 최대 지속은 upstream의 3번째 얼음 행동 판정 기준 적용 |
| `B_FIRST_TURN_MOVE` | 속이기·만나자마자를 등장 첫 턴 이후 직접 선택할 수 없도록 처리 |
| `B_SALT_CURE_DAMAGE` | 턴 끝 피해를 일반 1/16, 물·강철타입 1/8로 처리 |
| `B_BELCH_SELECTABLE` | 나무열매를 먹지 않았어도 트림 선택은 가능하고, 실행 시 조건에 따라 실패 |
| `B_STUFF_CHEEKS_SELECTABLE` | 나무열매가 없어도 볼가득넣기 선택은 가능하고, 실행 시 실패 |
| `B_SPIT_UP_SELECTABLE` | 비축이 없으면 토해내기 직접 선택 불가 |
| `B_MOVES_THAT_REMOVE_TYPE` | 불사르기·전광쌍격의 해당 타입 조건에 따른 직접 선택 제한 |
| `B_LAST_RESORT_SELECTABLE` | 다른 기술 사용 조건을 충족하지 못하면 비장의무기 직접 선택 불가 |
| `B_FAINT_MOVE_EFFECT_TIMING` | 사용자가 기절했을 때도 남도록 정해진 기술 효과 처리 |
| `B_SHEER_FORCE_AGAINST_ABILITIES` | 우격다짐과 상대 반응 특성의 Champions 설정 연결 |
| `B_ENCORE_PRIORITY` | 앙코르로 강제된 기술의 우선도 반영 |
| `B_UNSEEN_FIST_PIERCING_DRILL` | 해당 특성으로 방어를 관통할 때 피해 25% 및 접촉 방어 효과 처리 |

기술 선택 허용과 실행 성공은 구분해 줘. 트림·볼가득넣기의 선택을 허용한다고 사용 조건까지 무시하는 것은 아니야.

사용자 기절 후 효과도 모든 기술에 일괄 적용하지 말고, upstream의 기술별 범위와 예외를 따라 줘. 보호를 원래부터 무시하는 기술·일격기 등도 해당 예외를 보존해 줘.

### 1-2. 설정과 실제 구현을 구분

우격다짐과 발끈·나쁜손버릇 등의 상호작용은 `#10151` 자체에 미구현 부분과 `KNOWN_FAILING` 검사가 있으므로, 설정만 추가하고 효과까지 구현 완료라고 보고하지 말아 줘.

현재 HnS에 이미 있는 부분, 이번 PR에서 구현되는 부분, 1.17.1 범위의 후속 PR에서 처리되는 부분을 대조해 줘. 남는 미구현 항목은 별도로 보고하고, 이를 완성한다는 이유로 목표 밖의 upcoming 변경을 임의로 추가하지 말아 줘.

이미 들어온 Champions 수면·기술 데이터·메가진화 특성과 HnS 고유 구현은 보존해 줘.

### 1-3. #10282는 실제 코드 수정까지 반영

## 2. 재확인 92 — 실제 남은 설명 폭으로 계산

**A안으로 진행해 줘.**

요약 화면의 기술·콘테스트 설명은 폭 160px인 창의 `x=6`에서 출력하므로, 글꼴 선택에 사용할 실제 남은 폭은 **154px**야. 가능하면 창 폭과 출력 시작 위치를 기준으로 계산해 줘. 다른 설명창까지 일괄 154px로 바꾸지는 말아 줘.

이미 적용한 `GetDescriptionFontIdToFit`·`WrapDescriptionFontIdToFit`의 안전 처리는 유지해 줘.

- 기본 글꼴로 들어가면 그대로 사용
- 넘칠 때만 실제로 더 좁아지는 후보 확인
- 어떤 글꼴로도 들어가지 않으면 넘침으로 남기고 보고
- 문장 자르기·공식 줄바꿈 변경·창 크기 변경은 하지 않음

영문 콘테스트 설명 20개가 좁은 글꼴로 바뀌는 것은 이번 결정에 따른 화면 변화로 기록해 줘.

향후 한글도 실제 폭을 기준으로 처리해 줘. 한글은 후보 글꼴에 따라 폭이 그대로이거나 더 넓어질 수 있으므로, 좁은 글꼴이면 반드시 줄어든다고 가정하면 안 돼.

이번에는 폭 계산만 수정하고 아직 미번역인 기술 설명을 새로 한글화하지 말아 줘.

## 5. 재확인 95 — 배틀아레나 기존 점수 유지

**A안으로 확정할게. 현재 HnS의 점수 보존 처리를 유지해 줘.**

`#10311`의 `end`·`end2` 통합과, 결과가 확정된 뒤 `MoveEndClearBits`에서 아레나 점수를 계산하는 구조는 유지해 줘.

점수 함수는 이미 넣어 둔 다음 두 보정을 유지하면 돼.

1. 싱글 아레나에서 공격자 자신의 빈 결과를 추가 가점으로 계산하지 않도록 제외
2. 방어 여부는 기술을 사용한 공격자를 기준으로 확인

이미 반영된 보정이므로 중복 추가할 필요는 없어. **기존 점수를 보존하면서 내부 구조 정리는 이식하는 결정**이야.

upstream 개발자가 추가 점수까지 의도했는지, 공식적으로 버그로 인정했는지는 미확인이므로 단정하지 말아 줘. ‘HnS가 기존 점수를 유지하기로 결정한 보정’으로 기록해 줘.

추후 검증은 일반 공격·상성·실패·방어·자기 자신에게 쓰는 기술, 한 기술당 계산 횟수와 3턴 뒤 실제 판정 결과를 비교하는 범위로 정리해 줘. 이번에는 코드 경로의 정적 확인까지만 진행해 줘.

## 6. 인주시티 무용극장 — HGSS 조우곡·연출 순서 수정

**전통 무용수 5연전의 조우 BGM이 회전·접근 전에 시작되도록 HGSS 원작과 맞춰 줘.**

수정 대상:

`data/maps/EcruteakCity_Theater_hns/scripts.inc`

원작 근거:

[`pret/pokeheartgold/files/fielddata/script/scr_seq/scr_seq_0928_T27R0501.s`](https://github.com/pret/pokeheartgold/blob/master/files/fielddata/script/scr_seq/scr_seq_0928_T27R0501.s)

원작은 다섯 배틀 각각의 연출 시작 전에 다음 명령을 실행해.

```asm
StopBGM 30
PlayBGM SEQ_GS_EYE_MAIKO
```

그다음 회전·접근·대사 뒤 배틀이 시작돼. HnS에서는 대응곡 `MUS_HG_ENCOUNTER_KIMONO_GIRL`을 사용해 줘.

현재 `trainerbattle_no_intro`에는 자동 조우곡 재생이 활성화되어 있지만 별도의 배틀 전 대사 없이 바로 배틀로 이어져. 음악이 누락된 것인지 너무 짧게 재생되는 것인지는 실기 청취와 구분하고, 이번에는 코드상 재생 시점을 원작에 맞춰 줘.

### 6-1. 공통 음악·연출 순서

1. 기존 BGM 종료 및 전통 무용수 조우곡 시작
2. 해당 무용수의 회전·접근
3. 배틀 전 대사
4. 배틀 시작

`fadeoutbgm`·`playbgm` 등 기존 명령으로 구현하되, `StopBGM 30`과 HnS 명령의 인자 단위·대기 여부를 확인해서 전환 방식을 정해 줘. 숫자 30을 그대로 옮기거나 임의 지연을 넣는 것으로 같은 연출이라고 단정하지 말아 줘.

페이드가 끝나기 전에 새 곡을 시작해 전환이 무시되는지도 코드 흐름으로 확인해 줘. `playbgm`의 `save_song`은 **FALSE**로 지정해서 저장된 맵 BGM을 덮어쓰지 않도록 해 줘.

### 6-2. 옥희 — 준비 수락 후 음악·회전·마지막 대사

현재 `LegendaryCutscene`에 있는 옥희의 회전은 준비 수락 이후로 옮겨 줘.

- 기존 첫 등장 설명 유지
- 배틀 준비 여부 확인
- 거절하면 기존 거절 이벤트로 진행하며 조우곡은 재생하지 않음
- 수락하면 `MUS_HG_ENCOUNTER_KIMONO_GIRL` 재생
- 옥희 회전 동작
- HGSS 원작의 마지막 배틀 전 대사
- 배틀 시작

원작의 음악·회전 뒤 출력하는 `msg_0618_T27R0501_00045`에 대응하는 대사를 확인해 줘. HGSS 공식 한국어를 기준으로 반영하고 임의로 새로 쓰지 말아 줘.

`VAR_ECRUTEAK_CITY_THEATER`의 상태 저장과 거절 후 재도전 경로는 유지해 줘. 처음 수락하거나 거절 뒤 다시 수락하는 경우 모두 음악과 회전이 정상 실행되어야 하고 회전이 중복되면 안 돼. 방향 보정과 전투 시작 조건도 필요한 위치에서 유지해 줘.

### 6-3. 수정·난주·예솔·태희 — 동작과 대사 보존

다음 네 이벤트에서는 각 `playse SE_M_PETAL_DANCE` 이전에 조우곡을 시작해 줘.

- 수정: `EcruteakCity_Theater_EventScript_NaokoBattle`
- 난주: `EcruteakCity_Theater_EventScript_MikiBattle`
- 예솔: `EcruteakCity_Theater_EventScript_SayoBattle`
- 태희: `EcruteakCity_Theater_EventScript_KuniBattle`

현재 이동 방향·걸음 수·대사 중 원작과 일치하는 부분은 유지하고, 회전·접근·대사 동안 조우곡이 이어지게 해 줘.

앞 무용수 퇴장 뒤 다음 무용수의 연출 시작 때 조우곡을 새로 시작하는 것은 원작 흐름에 맞춰 처리하면 돼. 막아 달라는 중복 재생은 **한 무용수의 연출이 끝나고 배틀에 들어가기 직전에 같은 조우곡을 다시 시작하는 것**이야.

### 6-4. 이 다섯 배틀에서만 자동 조우곡 생략

이벤트에서 조우곡을 미리 재생하므로, 이 다섯 배틀의 `trainerbattle_no_intro`에서는 자동 조우 음악 재생을 생략해 줘.

현재 `asm/macros/event.inc`의 래퍼가 자동 재생을 켜므로, 다음 중 변경이 작은 방식으로 처리해 줘.

- 기존 두 인자 사용처를 보존하는 선택 인자 추가. 기본값은 기존처럼 자동 재생 활성화
- 무용극장 5연전 전용 래퍼를 만들어 자동 재생만 비활성화

이 다섯 호출에서만 자동 재생을 끄고 다른 트레이너의 조우곡은 유지해 줘.

공통 배틀 음악 함수 전체는 수정하지 말고, 기존 `no_intro`의 배틀 종료 후 스크립트 복귀·방향 처리·트레이너 플래그 처리도 보존해 줘.

### 6-5. 보존할 범위

- 다섯 무용수의 배틀 순서와 트레이너 데이터
- 회전·접근·퇴장 동작 자체
- 원작과 일치하는 기존 대사
- `settotemboost` 등 기존 전투 보정과 파티
- 배틀 결과·진행 상태 변수·재도전 조건
- 루기아·칠색조 분기 및 방울 획득
- 5연전 이후 전설의 포켓몬 관련 이벤트
- 기존 전투 BGM·승리 후 처리·패배 대사

옥희의 연출 순서와 명시한 마지막 대사 외의 텍스트는 추가 수정하지 말아 줘. HGSS와 다른 패배 대사도 이번 대상은 아니야.

**신도지방의 미하루·요코·시즈코 세 명은 대상에서 제외해 줘.** HnS 고유 스토리 NPC이므로 이번 5연전 연출을 확대 적용하지 말아 줘.

## 7. 기존 승인 및 작업 범위

팝업 종료를 기다리는 **재확인 36의 B안은 이미 승인한 결정**이야. 다시 선택을 묻지 말고 기존 지시를 유지해 줘. `#10268`과 반감열매 경로의 대기 처리 등 실제 반영 여부는 이번 완료 보고에서 구분해 줘.

기존 한글 텍스트·메가진화 특성·HnS 고유 기능·AI 교체 무한 루프 방지 가드·세이브 호환성 보호 원칙도 유지해 줘.

이번 신규 번역은 명시한 배틀 문장과 옥희의 HGSS 공식 대사에 한정해 줘. 미번역 기술 설명이나 다른 기존 대사는 추가 번역하지 말아 줘.

메인 로컬 저장소에는 손대지 말고 친구가 작업 중인 `pokehns-expansion-kor` 브랜치에서 필요한 부분만 수정해 줘. 메인 로컬의 `pull`·`push`·`reset`·`rebase`·`restore`나 번역 작업과의 중간 통합은 진행하지 말아 줘.

- 기존 선별 이식·후속 리팩터와의 중복 여부
- 475.5~475.8 순서표의 적용 상태

**재확인 92~95**

- 설명 폭 계산 위치와 다른 창에 대한 영향
- 세 구슬의 최종 문장과 팝업 유지 여부
- 아레나 계산 위치·자기 칸 제외·공격자 방어 검사 유지 여부

**무용극장**

- HGSS와 수정 후 HnS의 음악·동작·대사 순서 비교
- 다섯 무용수 각각의 음악 시작 위치
- 배틀 직전 조우곡 중복 재시작 방지 방법
- 옥희의 첫 도전·거절·재도전 분기와 상태 변수 보존
- 5연전 종료·패배 후 맵 BGM 및 전설 이벤트로 이어지는 경로
- 다른 `trainerbattle_no_intro` 사용처와 신도지방 세 NPC에 대한 영향 여부

정적 확인은 소스·스크립트 분기·명령 인자·공식 원문·변경 전후 데이터 비교처럼 **빌드하지 않고 확인 가능한 범위**에서 진행해 줘.

빌드·자동 테스트·세이브 정적 비교 도구 실행·실제 음악 청취·mGBA 검사는 이번에 실행하지 말아 줘. 확인하지 못한 결과를 이전 ROM의 PASS로 대신하지 말고 미실행으로 적어 줘.

기존 사용자 실기 PASS는 당시 ROM과 확인 범위를 보존해 줘. 이번 변경은 추후 새 ROM에서 내가 직접 확인할게. 지금 ROM을 만들지 않으므로 새 해시는 필요 없고 수정 기준과 완료 커밋을 알려 줘.

남은 full-sync 목표는 기존처럼 1.17.1까지 유지하고, 이번 결정 반영과 무용극장 수정 결과부터 보고해 줘.
