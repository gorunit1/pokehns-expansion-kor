# HnS 후속 결정 — HGSS 표시 클래스 조우곡 / 한글 설명 글꼴 방어

79·조우 BGM·목호 장면과 10-24b 수정 결과 확인했어. 알기술 전수, 수영팬티소년 23명 조우곡, 목호전 후 등장 음악, 회복·방어 애니메이션, 설명 폭 맞춤, AI 테라 설정, 화학의힘 이름 정정은 보고한 방향으로 유지해 줘.

남겨 둔 조우곡 질문 두 개와 재확인 91은 아래처럼 결정할게. 이번 추가 변경은 **조우곡 25개 엔트리와 설명 화면의 글꼴 선택 방어**로 나누어 진행해 줘. 사용자 mGBA 실기는 별도로 확인할게.

## 1. 조우곡의 기준 — HGSS 표시 클래스에 맞춤

**트레이너 발견 시 나오는 조우곡은, 게임에 표시되는 트레이너 클래스에 대응하는 HGSS 곡으로 맞춰 줘.**

이번에 바꾸려는 것은 발견 음악이야. 상금·볼·랜더마이저 등의 기존 동작을 보존하기 위해 둔 `Behavior Class`는 그대로 유지해 줘.

예를 들어 표시 클래스가 새 조련사인데 동작 클래스가 폭주족이라면, 발견 음악만 새 조련사에 맞추고 나머지 동작은 기존대로 두면 돼.

기존의 ‘동작 클래스에 맞는 조우곡도 보존’ 방침은 **이번에 지정하는 25개 엔트리의 조우곡에 한해 변경**하는 것으로 기록해 줘.

### 1-1. 질문 1 — 동작 클래스 때문에 다른 20개 엔트리

보고한 표를 기준으로 다음과 같이 `Music`만 바꿔 줘.

| 트레이너 | 표시 클래스 | 변경할 HGSS 조우곡 |
|---|---|---|
| ROY·BRET | Bird Keeper | `MUS_HG_ENCOUNTER_BOY_1` |
| COLETTE·SHIRLEY·HILLARY 3개 엔트리 | Teacher | `MUS_HG_ENCOUNTER_GIRL_1` |
| COREY | Burglar | `MUS_HG_ENCOUNTER_SUSPICIOUS_1` |
| DORIS | Medium | `MUS_HG_ENCOUNTER_SAGE` |
| RONALD·BRAD·DOUGLAS | Boarder | `MUS_HG_ENCOUNTER_SUSPICIOUS_2` |
| TREVOR 3개·ALEX 3개·ALLAN | Pokefan 남성 | `MUS_HG_ENCOUNTER_SUSPICIOUS_2` |
| THOM_AND_KAE | Double Team | `MUS_HG_ENCOUNTER_BOY_2` |

합계는 **20개 트레이너 데이터 엔트리**야. 같은 이름으로 여러 전투가 있는 경우도 보고한 대상에 포함하되, 실제 엔트리 식별자를 확인해서 수정 목록에 적어 줘.

### 1-2. 질문 2 — 성도 과학자 5명

**ROSS·MITCH·JED·MARC·RICH의 조우곡을 `MUS_HG_ENCOUNTER_ROCKET`으로 변경해 줘.**

HGSS 원작의 과학자 조우곡은 성도에서 ROCKET, 관동에서 SUSPICIOUS_1에 대응하므로, 보고한 성도 과학자 5명은 성도 기준으로 맞출게.

이 다섯 명도 `Music`만 변경하고, 표시 클래스 Scientist와 동작 클래스 Collector는 그대로 유지해 줘. 관동 과학자의 음악까지 ROCKET으로 일괄 변경하지는 말아 줘.

### 1-3. 기존 음악과 트레이너 동작 보존

이미 반영한 수영팬티소년 23명의 SUSPICIOUS_2는 그대로 유지해 줘.

이번 조우곡 수정으로 다음 사항은 바꾸지 말아 줘.

- 표시 클래스와 동작 클래스
- 이름·그림·오버월드·맵 배치
- 상금 계산·볼·AI·파티와 개체 데이터
- 배틀 BGM과 승리 BGM
- 관장·사천왕·챔피언·라이벌·시설 등의 기존 특수 이벤트 음악

HnS 고유 클래스는 앞서 보고한 대응을 유지해도 돼. 이번에는 새 판단이 필요한 다른 클래스나 트레이너까지 임의로 범위를 넓히지 말고, 추가 불일치가 발견되면 별도로 보고해 줘.

### 1-4. 조우곡 검증

원본 `trainers_hns.party`와 생성된 트레이너 데이터에서 **이번 25개 엔트리의 조우곡만 의도대로 바뀌었는지** 확인해 줘.

상금·볼·AI·파티 등은 관련 필드와 실제 참조 대상을 비교해서 보존 여부를 확인해 줘. 빌드로 주소가 이동한 것과 내용이 달라진 것은 구분해 줘.

가능한 대표 표본에서는 실제 시선 발견 흐름의 조우곡 선택과 배틀·승리·필드 복귀 시 음악 전환도 확인해 줘. 데이터 비교만 했다면 실제로 음악을 들은 검증과 구분해서 보고해 줘.

## 2. 재확인 91 — A안, 설명 화면에만 글꼴 선택 방어 적용

**A안으로 진행해 줘. 이번에 수정한 설명 출력 5개 범위에서, 실제 문자열 폭이 줄어드는 경우에만 다른 글꼴을 선택하도록 방어해 줘.**

HnS에서는 한글 글리프가 NORMAL·NARROW에서 8px인데 NARROWER에서 11px이므로, 글꼴 이름이나 단계만 보고 좁아질 것이라고 가정하면 안 돼.

현재 영문 설명을 창에 맞추는 기능은 유지하면서, 긴 한글 설명이 오히려 더 넓어지는 경우를 막아 줘.

### 2-1. 수정 범위

다음 설명 출력 범위에 한정해 줘.

1. 요약 화면 특성 설명
2. 요약 화면 기술 설명
3. 요약 화면 콘테스트 설명
4. 기술 떠올리기 기술 설명
5. 배틀 기술 정보창 설명

콘테스트 설명처럼 호출 위치가 여러 곳이면 모두 포함해 줘.

공통 `GetFontIdToFit` 전체의 동작을 바꾸어 가방 도구 설명·기술 이름 등 다른 화면에까지 적용하는 B안은 이번에 진행하지 말아 줘. 설명 전용 보조 처리가 필요하다면 호출 범위를 위 설명 화면으로 제한해 줘.

### 2-2. 글꼴 선택 기준

- 기본 글꼴로 창 안에 들어가면 그대로 유지.
- 넘치는 설명은 실제 문자열을 후보 글꼴로 측정.
- 기존보다 실제 폭이 줄어드는 후보만 선택.
- 어느 후보도 폭을 줄이지 못하면 기존 글꼴 유지.
- 폭이 줄어들어도 창을 여전히 넘는 문장은 미해결 항목으로 보고.
- 줄바꿈·문자 간격·제어 코드 등은 실제 출력 조건에 맞춰 측정.

글꼴 방어만으로 모든 문장이 반드시 들어간다고 처리하지는 말아 줘. 설명을 임의로 줄여 쓰거나 줄바꿈·창 크기를 바꾸는 것은 이번 요청에 포함하지 않을게.

### 2-3. 글꼴 회귀 검사

다음 조건을 구분해서 확인해 줘.

- 짧은 영문 설명은 기존 글꼴 유지.
- 현재 개선된 긴 영문 설명은 계속 창 안에 들어감.
- 파동의방호 한글 설명은 기존처럼 정상 표시.
- 긴 한글 설명이 11px 글꼴로 바뀌어 더 넓어지지 않음.
- 한영 혼합 문장과 여러 줄 설명에서도 실제 폭을 기준으로 선택.
- 어느 글꼴로도 들어가지 않는 문장은 ‘들어감’으로 PASS 처리하지 않음.
- 배틀 정보창의 한글 머리줄·제어 코드와 설명 뒤 글꼴 복구 유지.
- 수정 범위 밖 화면의 기존 글꼴 선택은 그대로 유지.

긴 한글 검사용 문자열은 테스트용으로 준비해도 돼. 실제 게임의 미번역 설명을 이번에 새로 한글화할 필요는 없어.

현재 보고한 영문 설명 74개·특성 설명 18개는 당시 문자열 기준의 측정값으로 남기고, 영구적인 대상 수로 고정하지 말아 줘.

## 3. 기존 반영 내용과 승인 상태 정리

알기술 전수 79, 목호전 후 호두·오박사 등장 BGM, 회복·방어 연출, 화학의힘 이름 정정은 이번 작업을 이유로 다시 바꾸지 말아 줘.

`B_AI_TERASTALLIZATION`의 **HnS 기본 FALSE**와 레드 두 개체의 테라 지정 삭제도 유지해 줘. ON일 때 레드 6마리가 스마트 테라 후보가 될 수 있다는 점은 기록으로 보존할게.

이번에 새로 결정한 것은 위 조우곡 25개와 재확인 91의 A안이야. 이미 승인한 항목과 새로 답이 필요한 항목은 기록에서 구분해 줘.
