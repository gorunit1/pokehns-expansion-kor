# HnS 트레이너 클래스·이름·스프라이트 조사 결과 답변 및 최종 작업 방침

1단계 조사 결과 확인했어. 공식 한국어 원문과 원작 트레이너의 위치·파티·클래스까지 대조해 준 방향에 동의해.

다만 이번 작업의 최우선 목표를 조금 더 명확히 할게.

**HnS의 메인 스토리에 실제 등장하는 트레이너를 HGSS 원작의 동일 인물과 대응시켜, 클래스명·배틀 스프라이트까지 가능한 한 원작대로 복원하는 것이 목표야.**

트레이너 이름이 다르더라도 같은 맵의 위치, NPC 배치, 파티, 재대결 관계를 함께 확인해 줘.

`Behavior Class`를 별도로 두어 HnS의 상금·몬스터볼·BGM·랜더마이저 동작을 보존하는 설계에는 동의해. 기존 트레이너 ID와 프런티어 동작도 유지해 줘.

## 1. 질문 13개에 대한 답변

**Q1. 로켓단 클래스명의 띄어쓰기**

HGSS 공식 원문인 `로켓단간부`, `로켓단보스`를 사용해 줘.

다만 더 높은 번역 우선순위의 공식 게임에 동일한 직업의 다른 표기가 있다면 먼저 대조해 줘.

**Q2. 연구원 클래스명**

HGSS 공식 클래스명인 `괴짜 연구원`을 사용해 줘.

**Q3. 공식 번역 출처**

마스터즈 EX와 2002년 금·은 한국어판 모두 공식 출처로 인정할게.

다만 기존에 정한 공식 번역 우선순위를 유지하고, 같은 인물의 표기가 다르다면 더 최신 공식 표현을 우선해 줘.

마스터즈 EX는 기존 우선순위에 없는 작품이므로, 다른 공식 작품에서 대응 표현을 확인하기 어려운 인물의 보조 출처로 활용해 줘.

**추가로 《포켓몬스터 스페셜》의 한국어 정식 출판본에서 사용한 인명·직업명 번역도 참고해 줘.**

포켓몬 공식 게임에서도 다른 공식 매체와 동일한 한국어 명칭을 사용하는 사례가 있으므로, 게임의 공식 한국어 번역이 확인되지 않는 이름을 결정할 때 참고 자료로 활용하고 싶어.

다만 게임의 공식 한국어 텍스트와 만화의 정식 한국어 번역은 출처를 구분해 기록해 줘. 게임 공식 표기가 확인된다면 기존 게임 번역 우선순위를 먼저 적용해 줘.

**Q4. 프런티어 클래스 4개와 브레인 이름**

공식 한국어 표기가 없다면 pokeemerald-kr 번역을 참고해 줘.

살롱 메이든·돔 에이스·팰리스 메이븐·개발자와 TUCKER·SPENSER도 이 기준을 적용하되, 공식 명칭과 팬 번역의 출처를 구분해 줘.

**또한 《포켓몬스터 스페셜》 한국어 정식 출판본에 해당 프런티어 브레인이나 직책이 등장한다면, 그 번역도 함께 조사해 줘.**

게임 공식 한국어 명칭이 없는 경우에는 pokeemerald-kr과 《포켓몬스터 스페셜》의 번역을 비교해 자연스럽고 일관된 표기를 선택해 줘. 만화의 정식 번역을 사용했다면 그 출처를 명시해 줘.

**Q5. NARD·RICHARDO**

HGSS의 Richard·Ned와 동일 인물인지 확실하지 않다면 일단 보류해 줘.

불탄탑의 정확한 위치·파티·원작 이벤트까지 추가 대조한 뒤 결정하자.

**Q6. JAIME·ALLAN**

HGSS에 대응 인물이 없는 크리스탈 전용 트레이너라면 크리스탈 원작 클래스를 복원해 줘.

HGSS에 동일 인물이 있다면 HGSS 클래스를 우선해 줘.

**Q7. ALEX**

동일 인물 대응이 확정됐다면 남성 애호가클럽으로 복원해 줘.

클래스·배틀 스프라이트는 함께 수정하고, 오버월드 스프라이트는 원작과 현재 HnS의 배치를 조사한 후 교체 여부를 결정하자.

**Q8. 미배치 61명**

실제 맵·이벤트에서 호출되지 않는 미배치 트레이너라면 이번 수정에서 제외해 줘.

단, 단순히 사용되지 않는다고 추정한 것이 아니라 실제 맵·스크립트 참조 여부를 확인해 줘.

나중에 등장할 가능성이 있으므로 기존 데이터는 삭제하지 말아 줘.

**Q9. Gender 필드**

원작과 동일 인물임이 확인된 트레이너는 HGSS의 성별 설정으로 복원해 줘.

다만 seq 400 이후 시드 계산에 영향이 있다면 기존 HnS의 랜더마이저 결과를 보존할 수 있도록 별도 값이나 호환 처리 방안을 적용해 줘.

**Q10. 원작 그림이 없는 클래스 및 추가 에셋**

이 항목은 아래 2~4절의 방침을 적용해 줘.

현재 SoulGold에서 추가로 가져올 배틀 스프라이트는 `scientist.png`와 로켓단 조무래기 남녀 그림으로 제한할게.

다른 HGSS 스프라이트는 우선 기존 개조롬의 공개 에셋과 사용 조건을 조사해 줘.

**Q11. Collector 그림**

프런티어의 Collector에는 원래 HnS에서 사용하던 에메랄드 계열 `collector.png`를 복원하는 방향으로 진행해 줘.

단, 먼저 실제 스토리와 프런티어의 사용처를 모두 확인해 줘. 자세한 사항은 아래 3절에 정리했어.

**Q12. 포켓기어 통화 화면**

트레이너 이름만 먼저 한글화되고 대사가 영문으로 남아 있어도 괜찮아.

NPC 대사와 포켓기어 통화 대사 전체 번역은 나중에 진행할게. 이번에는 기존 대사를 번역하지 말아 줘.

**Q13. 동일 인물 추정 14명과 로켓단 조무래기 27명**

동일 인물이라는 근거가 부족한 경우에는 고유 인명 번역을 보류해 줘.

로켓단 조무래기처럼 인물의 고유 이름이 아니라 일반 호칭을 표시하는 경우에는 공식 한국어 클래스·호칭을 적용해도 좋아.

단, 불확실한 고유 이름을 임의로 붙이지는 말아 줘.

## 2. HGSS 스프라이트 확보 방침

원작과 일치하는 스프라이트가 부족한 13개 클래스는 내가 모두 새로 만들기보다, **다른 pokeemerald 또는 FRLG 기반 개조롬에서 공개된 HGSS 스프라이트를 우선 찾아보고 싶어.**

다른 제작자가 이미 만든 64×64 트레이너 스프라이트가 있다면 재활용할 수 있는지 조사해 줘.

다만 출처만 표시하면 무조건 사용 가능한 것은 아니므로, 다음 사항을 확인해 줘.

- 실제 원 제작자와 공개 출처
- 에셋 사용·수정·재배포 허용 여부
- 크레딧에 필요한 표기
- 원작 HGSS 그림과의 일치 여부
- HnS의 64×64·16색 규격에 맞게 변환 가능한지

사용 허가가 명확한 에셋은 출처를 기록하고 활용해 줘.

사용 조건이 불명확하거나 허가가 필요한 에셋은 임의로 이식하지 말고 알려 줘.

적합한 공개 에셋이 없다면 내가 직접 제작하는 것도 고려할게.

이미 만들어 둔 스프라이트는 다음과 같아.

- `leader_brock_hns.png` — 웅, HGSS풍으로 새로 제작하고 세로 위치도 4px 보정 완료
- `teacher_hns.png` — 선생님, 제작 완료
- `medium_hns.png` — 무당, 제작 완료

Teacher·Medium은 PNG와 PAL을 준비했어. Medium은 GBA 16색 제한에 맞춘 최종 수정본을 사용해 줘.

웅 역시 기존 비교 사진의 그림을 기준으로 다시 제작할 필요는 없어. 필요하다면 최종 PNG와 PAL을 다시 전달할게.

## 3. Scientist·Collector·Super Nerd의 스프라이트 재분류

이번 조사에서 SoulGold에서 이식한 `collector.png`가 실제로는 HGSS의 이과계의 남자 그림이라는 사실을 확인했어.

따라서 다음 방향을 검토해 줘.

**연구원**

SoulGold의 `scientist.png`를 새 Trainer Pic ID로 등록해 줘.

HGSS 원작의 괴짜 연구원에 대응하는 HnS 스토리 트레이너는 이 신규 그림을 사용하도록 해 줘.

**이과계의 남자**

현재 이식된 SoulGold의 `collector.png`는 `super_nerd_hns.png`에 대응하는 그림으로 재분류하는 방향이 좋아 보여.

현재 `super_nerd_hns.png`와 실제로 비교해 보고, HGSS의 이과계의 남자 스토리 트레이너에게 올바른 그림을 배정해 줘.

기존 그림을 교체한다면 교체 전 파일도 보존해 줘.

**Collector**

HGSS 원작의 메인 스토리에는 Collector라는 별도 트레이너 클래스가 없는 것으로 알고 있어.

그런데 현재 HnS의 `trainers_hns.party`에는 다음 5명이 `Collector Hns`로 등록되어 있어.

- ROSS
- MITCH
- JED
- MARC
- RICH

이들은 프런티어가 아닌 일반 트레이너 데이터에도 존재하므로, 실제 메인 스토리에 배치되어 있는지 확인이 필요해.

각 트레이너의 맵 위치·이벤트 스크립트·파티를 확인해서 HGSS 원작의 괴짜 연구원이나 다른 클래스와 대응되는지 조사해 줘.

원작의 연구원이 맞다면 해당 트레이너의 클래스와 그림을 복원해 줘.

**실제 프런티어 전용으로 남는 Collector에는 SoulGold 이식 전의 HnS `collector.png`를 사용하도록 되돌려 줘.**

프런티어의 Collector까지 이과계의 남자 그림으로 변경된 상태는 복원하고 싶어.

HGSS 원작의 메인 스토리에는 Parasol Lady 클래스가 등장하지 않는 것으로 알고 있어.

그런데 HnS 일반 트레이너 데이터에는 다음 인물이 Parasol Lady로 설정되어 있어.

- BEVERLY
- RUTH
- GEORGIA
- JAIME

BEVERLY는 재대결 데이터도 별도로 존재해.

이 트레이너들이 실제로 어느 맵에 배치되어 있는지 확인해 줘.

특히 GEORGIA는 앞선 조사에서 미배치로 분류했으므로, 단순히 `.party`에 존재한다는 이유만으로 메인 스토리 등장 인물로 취급하지 말아 줘.

HGSS의 애호가클럽 여성과 대응하는 트레이너라면, 원작 클래스와 이미 이식된 `pokefan_f.png`를 배정해 줘.

JAIME처럼 크리스탈 전용 인물이라면 해당 원작의 클래스와 등장 위치를 기준으로 판단해 줘.

프런티어에서 사용되는 Parasol Lady는 기존 클래스와 그림을 유지해 줘.

**메인 스토리에서 HGSS와 맞지 않는 클래스가 남지 않도록 확인하는 것이 핵심이야.**

## 5. 나머지 트레이너도 같은 기준으로 조사

Collector·Parasol Lady뿐 아니라 HnS 메인 스토리의 전체 트레이너를 같은 방식으로 확인해 줘.

이름만 대조하지 말고 실제 맵 위치·NPC·파티·재대결 관계를 통해 HGSS 원작과 동일한 인물인지 판정해 줘.

원작과 다른 클래스가 설정되어 있으면 실제 클래스와 전투 스프라이트를 함께 복원해 줘.

단, 상금·몬스터볼·AI·파티·BGM·랜더마이저 등 기존 HnS 동작은 `Behavior Class`와 필요한 별도 설정을 사용해 보존해 줘.

신규 Trainer Pic ID는 기존 번호를 밀지 않도록 끝에 추가하고, 프런티어에서 사용하는 그림이 의도치 않게 변경되지 않도록 확인해 줘.

## 6. 오버월드 스프라이트

오버월드 스프라이트도 원작 재현에 중요한 요소이므로 조사 대상에 포함해 줘.

다만 **오버월드 스프라이트를 지금 바로 모두 교체하지는 말자.**

먼저 원작 HGSS와 HnS를 대조해 다음 사항을 정리해 줘.

- 현재 맵에 배치된 NPC의 오버월드 그림
- HGSS 원작에서 대응하는 NPC의 오버월드 그림
- 기존 HnS 그림을 그대로 사용할 수 있는지
- 새 그림이 필요한 경우 공개 에셋이 존재하는지
- 새 오버월드 그림 등록 시 다른 NPC에 미치는 영향

특히 포켓몬 매니아·중년 여성·보더 3종도 우선 조사만 진행해 줘.

기존 프런티어 또는 다른 지역에서 공유하는 그림까지 변경된다면 HnS 전용 ID를 사용해 분리해 줘.

나머지 SoulGold 미이식 그림(`psychic_m`, `blaine` 등)은 이번에는 추가로 가져오지 않을게.

## 8. 최종 작업 및 보고

이번 작업은 HGSS 원작과의 일치 여부를 가장 중요하게 생각하고 있어.

다만 원작 스프라이트가 아직 확보되지 않은 클래스는 기존 그림을 임의로 바꾸지 말고, 대응 관계만 확정한 뒤 그래픽 작업을 보류해 줘.

우선 조사 결과와 함께 다음 내용을 보고해 줘.

- Collector·Parasol Lady의 실제 메인 스토리 배치 여부와 HGSS 대응 결과
- 전체 트레이너 중 클래스·배틀 그림이 원작과 달라 수정이 필요한 목록
- 공개 개조롬에서 확보 가능한 HGSS 스프라이트와 사용 허가·크레딧 조건
- 현재 확보된 그림만으로 바로 복원 가능한 트레이너
- 오버월드 수정이 필요한 NPC와 신규 에셋 목록

확정된 부분은 단계별로 반영해도 좋아. 다만 출처나 대응이 불확실한 그림, 특히 오버월드 신규 제작이 필요한 항목은 먼저 보고해 줘.

NPC 이름·대사 한글화와 미배치 트레이너의 변경은 이번 작업에서 보류할게.

**최종 목표는 HnS에서 실제로 만나는 트레이너가 HGSS 원작의 해당 위치에 등장하는 인물과 클래스·이름·배틀 스프라이트까지 대응하도록 만들면서, 기존 HnS의 게임 동작은 보존하는 것이야.**
