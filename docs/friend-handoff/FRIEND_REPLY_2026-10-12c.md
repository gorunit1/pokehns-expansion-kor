HnS 묶음 15 후속 결과 확인 및 1.17.1 포트 질문 답변
세 가지 보고와 1.17.1 확장 계획 확인했어.
진홍빛고동·하드론엔진 문장 수정, 번역 정책 문서화, 메가진화 특성 전체 대조, 1.17.1 포트 계획 모두 보고한 방향에 동의해. 

1. 진홍빛고동·하드론엔진 및 번역 정책

커밋 600646ca43에서 네 문장을 SV·ZA 공식 원문과 줄바꿈까지 일치시킨 것 확인했어.
문장 폭도 HnS 메시지창 208px 이내라고 검증했으므로 이대로 확정할게.
docs/localization/TRANSLATION_POLICY.md에 정리한 번역 규칙도 그대로 유지해 줘.
추가로 질문했던 신규 배틀 메시지가 아닌 텍스트의 처리 방식도 동의해.
1.17.1까지 포팅하면서 새로 추가되는 메뉴·디버그 등 배틀 메시지가 아닌 텍스트는 우선 영문 그대로 유지하고 목록만 보고해 줘.
기존 HnS 텍스트는 내가 로컬에서 번역하고 있으므로, 별도로 요청하지 않는 한 수정하거나 번역하지 말아 줘.
최근의 트레이너 클래스명·트레이너 이름·인물명처럼 내가 명시적으로 요청한 번역만 예외로 처리해 줘.
NPC 대화와 포켓기어 텍스트는 기존 결정대로 HGSS 공식 한국어 원문 보존을 우선하며, 이 역시 내가 별도로 요청하지 않는 한 번역하지 않아도 돼. 

2. 메가진화 특성 대조 결과

대여르의 특성이 불굴의마음이 아니라 오기(Defiant)×3이라는 점 확인했어.
디스코드 요약의 오기였고 실제 코드에는 문제가 없었던 것으로 이해했어. 기존 HnS 값을 그대로 유지해 줘.
메가진화 포켓몬 99개 전부가 내가 적용한 커밋 1821fd6749의 할당과 동일하며, full-sync 과정에서 변경된 항목이 0개라는 점도 확인했어.
앞으로도 이 할당을 보존해 줘.
1.17.1과 다른 HnS 메가 특성 9개 역시 기존 할당을 유지해 줘. 그중 실제 동작에 차이가 있는 히드런과 대여르도 현재 HnS 설정을 우선할게.
파동의방호 역시 이미 내가 구현하고 메가진화 포켓몬에 할당해 놓았으므로 변경하지 말아 줘.
#10777의 Aura Guard와 Unimplemented. 문자열은 이식하지 않고 HnS의 기존 한국어 이름·설명을 유지해 줘.
#10730 효과 코드도 이미 HnS에 구현한 내용과 같으므로 중복 적용하지 말아 줘.
메가진화 특성의 할당이나 효과는 앞으로도 기존 인수인계 문서를 최우선으로 확인해 줘. 

3. 1.17.1 포트 범위 확장

1.17.1이 2026년 9월 29일 정식 태그로 확정된 버전이라는 점 확인했어.
최종 목표를 pokeemerald-expansion 1.17.1까지 확장하는 계획에 동의해.
기존 1.17.0 순서를 그대로 완료하고, 이후 seq 519~556의 PR 38개를 upstream 병합 순서대로 추가해 줘.
1.17.1-A/B/C의 세 묶음으로 구분하는 방식도 동의해. 확정된 계획은 기존 port_sequence.tsv에도 반영해 줘.
이미 적용된 #10837과 HnS에 동등한 코드가 있는 #10816은 중복 이식하지 말아 줘.
1.17.1 이후의 1.17.2 주기나 upcoming 변경 사항은 이번 목표에 포함하지 않아도 돼. 다만 이미 HnS에 적용된 파동의방호 같은 기능은 계속 보존해 줘.
Q1. #10777 Champions M-C 기술 데이터
제안한 5개 변경 사항을 모두 수용할게. 

* 베어가르기: 위력 70 → 80
* 희망사항: PP 10 → 5
* 힘흡수: PP 10 → 5
* 스타어설트: 위력 150 → 170
* 전광쌍격: 펀치 기술 판정 추가(철주먹 적용)

HnS는 이미 Champions 데이터를 우선하는 설정이므로, 다른 Champions 기술 데이터와 동일하게 최신 값을 적용해 줘.
기존 메가진화 특성 할당은 건드리지 말고, 기술 데이터에 해당하는 변경 사항만 반영해 줘. 
그리고 "앞서 넣은 Champions 데이터처럼"이라 했는데 이전처럼 GEN_CHAMPIONS에만 기술 변경을 적용하는게 맞다면 그렇게 해줘.
Q2. #10660 녹화 배틀 난수 수정
upstream의 녹화 배틀 RNG 수정도 수용할게.
녹화 배틀의 난수 불일치를 고치는 변경이므로 정상적인 녹화·재생 동작을 우선하고 싶어.
다만 이식 전 ROM에서 저장한 녹화 배틀을 이식 후 ROM에서 재생할 때 호환성 문제가 생길 수 있다는 점은 기록해 줘.
가능하다면 기존 녹화본과 이식 후 새로 녹화한 배틀을 각각 재생해 비교하고, 호환성 문제가 확인되면 어떤 조건에서 발생하는지 알려 줘.
세이브 구조나 기존 세이브 데이터 자체를 변경하지는 말아 줘.
또한 이번 PR은 기존 AI 교체 무한 루프 방지 가드와 같은 난수·판단 순서 변수에 영향을 주므로, 레아&피아·FINLEY·MUALANI 등의 더블 AI 교체 회귀 테스트 2개도 반드시 다시 확인해 줘.
이식 전 녹화본의 완전한 재생 호환성을 보장하기 어렵다면, 그 사실을 명시적으로 기록하고 진행해도 괜찮아. 

4. #10822 기술 설명 파일 및 기타 주의사항

#10822가 수정하는 src/data/moves_info.h는 내가 로컬에서 한글화를 진행하는 파일이야.
따라서 보고한 대로 기술 설명 내용은 변경하지 말고, 빌드에 필요한 #if·COMPOUND_STRING 구조만 최소한으로 수정해 줘.
기존 문자열을 upstream의 영문 텍스트로 덮어쓰지 않도록 주의해 줘. 내 로컬 번역과 충돌 가능성이 있으면 먼저 알려 줘.
1.17.1에서 새 배틀 메시지가 없다는 점도 확인했어. 출력 순서나 문장 선택이 달라지는 5개 PR은 계획대로 BATTLE_MESSAGE_OUTPUT_CHANGES.md에 기록해 줘.
#10829의 방벽 타이머 문제는 아직 코드상 의심 단계이므로, 먼저 재현 여부를 확인해 줘. 실제로 재현되고 앞당김이 필요하다면 그때 별도로 알려 줘. 지금은 임의로 포트 순서를 변경할 필요 없어.
기존 HnS 고유 기능, 메가진화 특성, 한국어 텍스트, 세이브 호환성을 보존한다는 원칙은 1.17.1 작업에도 그대로 적용해 줘.
